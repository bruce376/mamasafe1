MongoDB Manual Startup Instructions
====================================

You requested to use Option 2 to start MongoDB. Since MongoDB requires
administrator privileges to start, you need to execute these commands manually.

STEPS TO START MONGODB:
=======================

1. Open Command Prompt as Administrator:
   - Press Windows key
   - Type "cmd"
   - Right-click "Command Prompt"
   - Select "Run as administrator"

2. Execute the following commands:
   
   cd "C:\Program Files\MongoDB\Server\8.3\bin"
   mongod.exe --dbpath C:\data\db --port 27017 --bind_ip 127.0.0.1

3. Keep the Command Prompt window open while using the application
4. Press Ctrl+C to stop MongoDB when done

WHAT HAPPENS AFTER MONGODB STARTS:
===================================

- MongoDB will run on localhost:27017
- The backend server (already running on port 5000) will automatically
  connect to MongoDB and switch from in-memory database to MongoDB
- No restart of the backend is required

CURRENT STATUS:
===============

✅ Backend Server: Running on http://localhost:5000 (using in-memory DB)
✅ Frontend Server: Running on http://localhost:3000
❌ MongoDB: Not running (requires manual administrator startup)

Once you start MongoDB manually, the backend will automatically connect
and use MongoDB for data persistence.
