MongoDB Startup Instructions
==============================

MongoDB has been successfully downloaded and installed at:
C:\Program Files\MongoDB\Server\8.3\bin

However, automated startup is failing due to system permission issues.
Please follow these manual steps to start MongoDB:

OPTION 1: Run the startup script
--------------------------------
1. Right-click on: C:\Users\ntare\Downloads\mamasafe\start-mongodb-final.bat
2. Select "Run as Administrator"
3. MongoDB will start in the command window
4. Keep this window open while using the application
5. Press Ctrl+C to stop MongoDB when done

OPTION 2: Start MongoDB manually
--------------------------------
1. Open Command Prompt as Administrator
2. Run the following commands:
   cd "C:\Program Files\MongoDB\Server\8.3\bin"
   mongod.exe --dbpath C:\data\db --port 27017 --bind_ip 127.0.0.1
3. Keep the command window open
4. Press Ctrl+C to stop MongoDB when done

After MongoDB is running:
-------------------------
1. Start the backend server: C:\Users\ntare\Downloads\mamasafe\start-backend-simple.bat
2. The backend will connect to MongoDB on localhost:27017
3. Start the frontend server: C:\Users\ntare\Downloads\mamasafe\run-frontend.bat

MongoDB Connection Details:
- Host: localhost
- Port: 27017
- Database: mamasafe
- Data Directory: C:\data\db

Troubleshooting:
---------------
- If MongoDB fails to start, check if port 27017 is already in use
- Ensure C:\data\db directory exists and has write permissions
- Check Windows Firewall settings for MongoDB
